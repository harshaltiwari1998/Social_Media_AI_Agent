# inbox - Pokemon fusion clips

Upload a Gemini fusion reveal clip here (GitHub website: **Add file -> Upload files**, then **Commit changes**).
Name it after the two Pokemon:

- `charizard+gyarados.mp4` - the fusion name comes from `backend/scripts/specs/fusion_pairs.json`
  (or is made from both names)
- `charizard+gyarados=charados.mp4` - use the name Gemini showed

The `fusion-inbox.yml` workflow starts on its own, makes a 9:16 short (names, fusion name + type, outro),
posts it to HarryBeast YouTube + the gaming Facebook Page + Instagram, and then deletes the clip from here.
Prompts: `F:/AI AGENT/pokemon_fusion_prompts.md` on the laptop.
